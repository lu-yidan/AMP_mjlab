# 平地五组训练统一评估：2026-11-07

结论：镜像＋CUDA Graph 组合显著节省训练循环耗时，但在本次测试中没有全面提升策略质量。原 BlinkCore 恢复更快，恢复早期的关节加速度更低。双判别器未显示明确优势。

## 协议

- 同一验证库、同一初态哈希、同一平地模型及标准动力学；1268 个恢复初态，每次20秒、不重置。成功要求 root 高度>0.65m、gz<-0.9 持续1秒。报告时间包含这1秒确认时间。
- 恢复初态包含 natural/low 376、procedural/low 512，以及恢复中后段；各组低位初态也全部成功。
- 12类速度命令，每类8个相同关节扰动；先站2秒再执行命令10秒，报告末5秒均值，无推力、随机化或命令平滑。
- BlinkCore 自动加载 EMA0.995 权重；SuperMimic 加载原策略权重。
- 已补测5步组40k存档，五组现已对齐40k。5步40k用了819.2M真实转移，2.5步40k用了409.6M；相同迭代数不等于相同采样预算。原35k结果保留在初次评测目录。

五组命令测试的末5秒站立率均为100%；恢复试验末5秒站立率也均100%。

镜像组合40k训练循环耗时4.545h，原BlinkCore为7.067h：耗时减少35.7%，吞吐约1.55倍。此处比较整个配置包，不能拆分镜像、图捕获与移除主机同步各自贡献。
镜像组合恢复前3秒关节加速度RMS为98.62，原BlinkCore为81.29，增加21.3%；整体成功时间1.719s vs1.689s。它的自然低位初态恢复更快(1.719s vs1.781s)，程序生成低位初态更慢(1.855s vs1.751s)，并非各分布一致改善。
双判别器相对单判别器（同为SuperMimic 2.5步WM2048）整体成功时间1.824s vs1.766s，早期关节加速度RMS91.25 vs80.19。本批实验未显示双判别器优势。

## 5步组35k→40k补测

- 同一1268初态，成功率均100%，成功时间1.847→1.778秒；前3秒关节加速度RMS79.25→91.14（约+15%）。恢复变快但该平滑性指标变差。
- 前进1/2/3m/s实际均值：0.976/2.033/2.960；后退−1m/s实际−0.847；左右侧移±0.5实际+0.507/−0.512；左右转向±1rad/s实际+0.953/−0.941。
- 12类命令末5秒站立率仍全部100%。左转、左右侧移均值较35k更准，但后退和右转偏差增大。没有全面超过2.5步或原BlinkCore。
- 对比SuperMimic单判别器2.5步40k，5步组消耗两倍真实转移，训练循环耗时9.17h vs7.55h；恢复时间1.778s vs1.766s，早期关节加速度91.14 vs80.19。此次未观察到增加采样步数的明确综合收益。

## 限制与后续

- 仅一个训练种子及标准平地动力学；100%成功说明该验证集合的成功率已饱和，不能推断复杂地形/推倒/真实硬件也全部成功。
- 关节加速度是50Hz控制频率有限差分的固定窗口指标，包含恢复和站立，不能单独代表视觉自然度或真实峰值冲击。
- 训练回合长度接近1000不等于独立恢复成功率；训练分模式MAE每5000仿真步更新一次，不能把重复记录当独立新测量。
- 后续优先以原BlinkCore作为动作质量参考，以镜像＋Graph作为效率候选；要拆分贡献可做Graph-only对照。当前不需要仅为提高已饱和的平地成功率盲目延长训练。
