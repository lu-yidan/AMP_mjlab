## 判据与核对

SR3：20 秒内开始站立并保持连续 3 秒，观察至 23 秒；头高至少 1.15 m、直立度至少 .90、双足载荷各大于 20 N。不要求额外安静站立、脱离投影，不采用历史压板无效筛选。平地 1024 次，Guided 和 Free-R 各 512 次，每场景四朝向均匀。

两组的初始 qpos/qvel、scene/direction/source 与 3k 保存数组完全一致，Free-R 板子参数审计通过。已从逐次结果核对全部成功计数；两组 terminated 均为零。JSON 中提供 Wilson 区间和朝向细分；固定评测种子与姿态库上的区间不等于多训练种子不确定性。

## 结论与下一步

- 5k 有引导组 Guided 高 4.49 个百分点，Free-R 低 2.34 个百分点；平地相同。
- Guided 的差别主要来自仰卧：有引导 116/128，无引导 95/128。伏卧分别 73/128 与 72/128，仍为主要短板。
- 相比自身 3k，有引导 Guided 从 433/512 到 431/512，Free-R 从 501/512 到 496/512，没有继续提升；无引导则从 389/512、493/512 提升到 408/512、508/512。
- 不能据此写成几何引导全面提高所有场景成功率，也不能将不同组各自最优 checkpoint 隐含为同预算配对。可用现有 10k checkpoint 做下一次同预算比较，无需等待新训练；本次未额外评测 10k、未停止训练、未修改论文表格。

检查时两组实际训练已约 11.4k / 11.8k，本次按用户要求只测 5k。GPU 0–3 有其他人的任务，评测临时与自己的训练共享 GPU 4/5，没有终止其他任务。
