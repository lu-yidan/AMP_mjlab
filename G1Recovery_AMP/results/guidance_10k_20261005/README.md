## 协议与验证

SR3：20 秒内开始站立，连续保持 3 秒，观察至 23 秒；头高 ≥1.15 m、直立度 ≥.90、双足载荷各 >20 N。无额外安静站立或脱离投影门槛，不使用历史压板无效筛选。全部预定试验进入分母，无重试。

每组平地 1024 次、Guided 512 次、Free-R 512 次，各场景内四朝向均匀。保存的初始 qpos/qvel、scene/direction/source 与 3k 的逐元素比较全部一致；Free-R 参数和文件哈希匹配。成功计数已从逐次结果核对，两组 terminated 均为零。Wilson 区间保存在各组 JSON 中；固定姿态库和评测种子上的区间不能代表多训练种子不确定性。

## 解读

10k 有引导的 Guided SR3 比无引导高 7.42 个百分点（452 对 414 次成功），Free-R 高 0.39 个百分点（506 对 504 次成功）。后者只有两次试验差别，应视为接近，不主张明显或稳定优势。

相对 5k，有引导的 Guided 提升 4.10 个百分点、Free-R 提升 1.95 个百分点；无引导 Guided 提升 1.17 个百分点、Free-R 下降 0.78 个百分点。有引导 10k 是目前已评测的 2k/3k/5k/10k 中自身两类压板成功率最高的 checkpoint，不能据此称其为全训练过程中最优或已收敛。

Guided 的优势主要来自仰卧（117 对 93 次成功）和右侧（128 对 115 次成功）。伏卧 79 对 78 次成功，仍是两组共同短板。现有证据支持当前训练种子的上下板收益，不支持“所有初始姿态、所有场景均全面改善”。
